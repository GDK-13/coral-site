Da linguagem ao editor

Uma experiência completa para aprender e construir.

A Coral oferece uma linguagem de propósito geral com módulos especializados sem esconder os fundamentos de programação nem exigir serviços externos para o fluxo cotidiano.

01

Português corrente

Condições, laços, consultas de tipo, conversões e operações naturais de texto, coleções, arquivos e JSON mantêm a leitura próxima da intenção do programa com equivalências determinísticas.

02

VS Code integrado

Coral Language 0.74.0 reúne LSP, depuração, IntelliSense, diagnósticos estruturados, testes, navegação e ferramentas de projeto.

03

Ciência e dados

Matemática, vetores, matrizes, estatística, regressão, reamostragem e experimentos reproduzíveis convivem com dados comuns da linguagem.

04

Gráficos 2D e 3D

Linhas, dispersão, barras, histogramas, incerteza, painéis, superfícies 3D e exportação para SVG, PNG, PDF e HTML interativo.

05

Web local e HTTP

Composição HTML, URLs, cliente HTTP e servidor local com limites explícitos, bytes preservados e rede iniciada somente quando solicitada.

06

Jogos e apresentação

Sprites, animação, colisão, câmera, mapas, HUD, transições, depuração visual e pontes com geração procedural.

07

Mundos e regras

08

Geração procedural

Sementes derivadas, campos, distribuição espacial e receitas reproduzíveis podem alimentar simulações, pesquisa e cenas de jogo.

Processos, ambiente, caminhos, diagnóstico do sistema e acesso opcional a capacidades de hardware permanecem separados da lógica do programa.

Ciência, visualização e Web

Do dado bruto a uma apresentação local.

A biblioteca científica e a base Web podem ser usadas separadamente ou combinadas. Você escolhe quando calcular, visualizar, salvar ou servir um resultado.

  • coral.numerico cobre estatística descritiva, regressão, bootstrap, permutação e geometria 3D.
  • coral.laboratorio organiza experimentos, parâmetros, medições, comparação e proveniência.
  • coral.graficos produz SVG local e pode exportar PNG, PDF ou HTML interativo quando solicitado.
  • coral.web.html e coral.web.url trabalham localmente com texto, marcação e endereços.
  • coral.web.http preserva corpo em bytes e só interpreta texto ou JSON sob demanda.
  • coral.web.servidor cria servidores locais explicitamente, com limites de corpo e encerramento controlado.
Controle explícito

Importar os módulos Web não acessa a rede. Criar uma especificação de gráfico não abre janela. Criar um servidor não abre porta até que o programa peça isso. A Coral mantém efeitos externos visíveis no código.

Instalação

Comece pelo pacote oficial da Coral.

A edição 1.7.2 inclui o runtime portátil corrente e Coral Language 0.74.0. Os artefatos nativos Linux preservados no pacote continuam identificados como 1.7.0.

Linux
bash Instalacao/Coral_Setup.sh
python3 Instalacao/Runtime/coral-1.7.2.pyz --versao
Runtime portátil
python3 Instalacao/Runtime/coral-1.7.2.pyz arquivo.coral

Para usar exatamente o runtime 1.7.2, prefira o runtime portátil ou o assistente da distribuição. Consulte o guia de instalação para distinguir os artefatos correntes dos binários nativos preservados.
