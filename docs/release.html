Coral 1.7.0

A Coral 1.7.0 reúne em uma distribuição pública única as capacidades atuais da linguagem, da biblioteca padrão, das ferramentas e do Livro Oficial.

Para quem programa

  • A sintaxe e as APIs públicas permanecem compatíveis com a edição estável imediatamente anterior.
  • A biblioteca atual inclui computação científica, gráficos 2D e 3D, Web local, cliente HTTP, servidor HTTP local, geração procedural, criptografia, jogos, simulação, sistema e hardware.
  • O runtime portátil é coral-1.7.0.pyz.
  • Coral Language 0.72.0 acompanha a distribuição para edição, navegação, testes e depuração no VS Code.
  • O Livro Oficial 1.7.0 acompanha a mesma edição técnica da linguagem.

Plataforma

Linux x86_64 é a distribuição nativa autoritativa desta edição. O pacote inclui instalador nativo e pacote .deb, além do runtime portátil.

Windows x86_64 não é declarado como plataforma nativa validada da Coral 1.7.0. Ferramentas portáteis relacionadas podem existir na distribuição, mas não substituem essa disponibilidade de plataforma.

Biblioteca e exemplos

A documentação corrente inclui os módulos científicos e Web presentes na distribuição, além de exemplos oficiais para matemática, estatística, laboratório, gráficos, integração científica, sistema, procedural e Web.

Como ler estas notas

Use esta página quando estiver atualizando a Coral ou precisar verificar uma mudança de compatibilidade, plataforma ou ferramenta. Para aprender recursos e APIs, use a documentação normal ou o Livro Oficial.
